# Informes de bugs

Los sube la app con el botón 🐞 (arriba a la izquierda): cada informe es una captura `.png` de la pantalla en el momento de pulsar y una nota `.md` con lo que escribiste y el contexto (pantalla, tiempo de batalla, mano, unidades en el campo, móvil).

Cuando se arregle un bug, su informe se mueve a `bugs/resueltos/`.
